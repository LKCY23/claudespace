# AutoResearchClaw skill adapter

This small package preserves seven skills from the existing installation, without
the Python runtime, configuration, credentials, caches or research output.

The public upstream baseline is 2984bb62323eb1abfe481e4b950e3a4c4cdbefa6 in
aiming-lab/AutoResearchClaw. The existing local repair added YAML frontmatter to
skills/researchclaw/SKILL.md. UPSTREAM.json records that repair and the file hashes;
the other skill content remains as captured from the verified local installation.

Install only on explicit selection as autoresearchclaw@claudespace. The runtime
and provider/project setup remain separate. Registration does not install, enable
or run this package.
